# 双人群学习闭环：需求与任务文档

> 状态：已评审，进入实现  
> 分支：`feat/dual-audience-learning-loop`  
> 日期：2026-11-17  
> 目标版本：v1.1

## 1. 背景

当前产品已经有不错的基础能力：单词默写、句子填空/整句默写、键盘优先输入、逐字批改、语音朗读、错题复习本和卡通视觉。但产品更像一个“练习页集合”，缺少让用户第二天回来的理由，也没有把两类核心用户区分开：

- **K12 学生**：需要轻量、鼓励式、每天可完成的练习；家长/老师能快速看到坚持和正确率。
- **成人考试用户**：目标明确，关心“我练的是不是 CET-4/6、考研、雅思、托福、GRE 的词”，需要进度、错题和效率。

这两类用户不应做成两个割裂的产品。正确做法是：**一套练习引擎 + 两条学习路线 + 一个每日学习面板 + 一个统一复习本**。

## 2. 目标与非目标

### 2.1 目标

1. 首页从“选参数”升级为“今天学什么”的学习面板。
2. 同时服务 K12 与成人考试用户，用户无需注册即可选择自己的路线。
3. 让“错题 → 复习 → 掌握”形成闭环，且第一次答错就能进入复习本。
4. 修复当前最影响体验的断点：设置丢失、再练一轮重复、单词错题不回流、答案直接泄露、调试按钮外露。
5. 保持现有卡通视觉与键盘优先体验，不引入登录、支付或后端服务迁移。

### 2.2 非目标（本版本不做）

- 不做账号体系、多用户隔离、云同步。
- 不做完整 SRS 算法（保留现有 `next_review_at` 字段，先做可解释的简化规则）。
- 不做 PWA、分享海报、AI 出题。
- 不重写句子练习的判分逻辑。
- 不引入新的 UI 组件库。

## 3. 用户画像与核心场景

### 3.1 K12 学生（校园成长）

- 典型目标：每天 10–20 个词，准备中考/高考，或者按 CEFR 循序渐进。
- 关键诉求：任务短、反馈快、有鼓励、能看到连续天数。
- 典型路径：首页 → 选“校园成长” → 选中考/高考/CEFR → 单词默写 → 完成 → 看到今日进度与错题。
- 成功标准：第一次使用 10 秒内能开始；完成后知道明天回来练什么。

### 3.2 成人考试用户（考试冲刺）

- 典型目标：CET-4/6、考研、雅思、托福、GRE 词汇。
- 关键诉求：词表匹配考试、进度明确、错题可集中复习、不要幼稚但可以轻松。
- 典型路径：首页 → 选“考试冲刺” → 选考试 → 单词默写 → 完成 → 复习本集中清错。
- 成功标准：能确认自己练的是目标考试词表；错词能在复习本里再次出现。

## 4. 产品方案

### 4.1 学习路线（Track）

首页新增“学习路线”选择：

| 路线 | 适用人群 | 词表选项 |
| --- | --- | --- |
| 校园成长 | K12 / 日常提升 | CEFR A1–C2、中考核心词、高考核心词 |
| 考试冲刺 | 大学生 / 考研 / 留学 | CET-4、CET-6、考研、雅思、托福、GRE |

- 路线和词表选择写入 `localStorage`，并通过 URL 参数恢复。
- 从练习页返回首页时，保留上一次的路线、词表、内容、等级、场景、模式、题数。
- 默认路线：校园成长；默认 CEFR 等级：A2（避免新用户直接面对全部 8460 词）。
- 选择考试词表时，等级筛选自动隐藏，避免“考试词表 × CEFR”双重过滤造成困惑。

### 4.2 今日学习面板（Dashboard）

首页 Hero 下方新增面板，数据来自本地 SQLite：

- 连续学习天数（streak）。
- 今日已完成题数 / 每日目标（默认 20，可后续做成可配置）。
- 今日正确率。
- 待复习句子数、待复习单词数。
- 最近 7 天练习量迷你柱状图。
- “继续上次”按钮：使用上次保存的设置直接开始。
- 无记录时显示引导文案，不显示空洞的 0。

数据来源：

- 句子：`practice_records`、`sentence_stats`。
- 单词：`word_records` 聚合。
- 新增 `GET /api/dashboard` 返回上述聚合结果。

### 4.3 统一复习本

复习本从“只复习句子”升级为双 Tab：

- **句子**：正确率 < 70%，且至少作答 1 次（第一次答错即可出现）。
- **单词**：聚合 `word_records`；答错次数 > 0 且尚未掌握（正确次数 < 3）即进入复习；正确率 < 70% 也保留。
- 每个 Tab 显示数量、平均正确率、清空按钮。
- 清空按范围执行：只清句子或只清单词，不再“清空错题本”却删掉全部记录。
- 单词卡片展示：单词、音标、释义、正确率、错误次数、最近作答时间。
- 支持“重练这一个单词”和“复习全部单词”。
- 句子保持“重练这一句”。

### 4.4 单词默写体验

- 第一次答错不直接展示完整答案，改为“字母级提示”：
  - 显示答案长度。
  - 已写对的字母保留，写错的字母用占位符。
  - 提示首字母。
  - 用户可点“看答案”或第二次答错后查看完整答案。
- 增加“再来一组”：重新抽题，而不是重复同一组。
- 保存真实用时：`timeSpent` 不再固定为 1 秒。
- 单词错题回流到复习本。
- 移动端隐藏键盘快捷键说明；保留触屏可用的操作按钮。

### 4.5 句子练习体验

- 移除生产环境右下角“🎉 测试动画”调试按钮。
- “再练一轮”重新抽题，不再重复同一批 50 句。
- “错题复习”开关改名为“只看待复习”，避免被误认为跳转。
- 移动端隐藏快捷键说明。
- 首次答错即可进入复习本（去掉 `total_attempts >= 2` 的限制）。
- 返回首页时保留筛选条件。

### 4.6 文案与视觉

- 去掉面向用户的 `npm run import:data`、`Tatoeba` 等开发/技术词。
- 句子内容统一叫“生活例句”。
- 低对比度的小字提升到 `text-ink/60` 左右；关键标签不小于 11px。
- 保留卡通风格，但答案输入区域使用更易辨认的字体（等宽/无衬线），避免 Comic Sans 影响字母辨别。
- 尊重 `prefers-reduced-motion`：减少动画时关闭漂浮/弹跳/礼花。
- 移动端首页开始按钮在首屏可见；如空间不足，使用底部粘性开始按钮。

## 6. 数据与接口设计

### 6.1 数据库

不新增核心表，复用现有：

- `practice_records` / `sentence_stats`：句子练习与复习。
- `word_records`：单词作答流水，新增按 `word`、`created_at` 的索引。
- `word_dict.tag`：考试词表来源，空格分隔的小写标签（`cet4 cet6 ky ielts toefl gre gk zk`）。
- `word_cefr`：CEFR 词表。

新增索引：

```sql
CREATE INDEX IF NOT EXISTS idx_word_records_word ON word_records(word);
CREATE INDEX IF NOT EXISTS idx_word_records_created ON word_records(created_at);
```

### 6.2 API

#### `GET /api/dashboard`

返回：

```json
{
  "ok": true,
  "streak": 3,
  "today": { "attempts": 12, "correct": 10, "accuracy": 83 },
  "review": { "sentences": 4, "words": 7 },
  "total": { "attempts": 128, "accuracy": 76 },
  "last7Days": [{ "date": "2026-11-11", "attempts": 20, "correct": 16 }]
}
```

#### `GET /api/words?level=A2&count=20&exam=cet4`

- `exam` 可选；按 `word_dict.tag` 过滤。
- `ids` 可选；用于复习本重练指定单词，按给定顺序返回。
- 返回 `total` 为当前筛选条件下的词数。

#### `GET /api/stats?type=review-words&limit=50`

返回单词复习列表，字段包含：

```json
{
  "word": "abandon",
  "phonetic": "əˈbændən",
  "translation": "放弃",
  "level": "B2",
  "total_attempts": 3,
  "correct_count": 1,
  "wrong_count": 2,
  "accuracy": 33.3,
  "last_attempt_at": "2026-11-17 08:00:00"
}
```

#### `DELETE /api/records?scope=sentences|words|all`

- `sentences`：只清句子记录与统计。
- `words`：只清单词记录。
- `all`：清全部（保留兼容，但复习本不再默认使用）。

### 6.3 本地存储

`localStorage` key：`dictation:settings:v1`

```json
{
  "track": "campus",
  "exam": "",
  "content": "word",
  "level": "A2",
  "category": "all",
  "mode": "fill",
  "count": "20"
}
```

## 7. 交互流程

### 7.1 新用户

1. 打开首页，默认“校园成长 / A2 / 单词默写 / 20 词”。
2. 看到今日面板的引导态：“今天先练 10 分钟，系统会记住你的进度。”
3. 点击开始，进入单词练习。
4. 完成后回到首页，今日面板出现完成题数、正确率、连续天数。

### 7.2 考试用户

1. 首页切到“考试冲刺”。
2. 选择“CET-4”。
3. 等级筛选隐藏，显示“CET-4 核心词”。
4. 开始练习；答错的词进入单词复习 Tab。
5. 第二天首页显示待复习单词数，点击直达复习本。

### 7.3 复习

1. 首页点击“待复习 7 词”。
2. 复习本默认打开单词 Tab。
3. 点击“复习全部单词”，进入 `/word?ids=...`。
4. 练对 3 次后该词从复习列表毕业。

## 8. 验收标准

- `npm run build` 通过。
- `npm run lint` 无新增错误（允许已有 warning，但需记录）。
- 首页刷新、从练习页返回、直接访问带参数的 URL，三种情况设置一致。
- 选择每个考试词表后，抽题结果的 `word_dict.tag` 均包含对应标签。
- 第一次答错句子/单词后，刷新复习本即可看到对应条目。
- 单词第一次答错时，页面不出现完整正确拼写；点击“看答案”后才出现。
- 复习本清空句子不影响单词记录，反之亦然。
- 移动端 375px 宽度下，首页开始按钮可见，快捷键说明不显示。
- 生产页面不存在“测试动画”按钮。

## 9. 实施顺序

1. 数据层：`word_records` 索引、考试词表过滤、单词复习聚合、dashboard 聚合、复习阈值调整、按范围清空。
2. API：`/api/dashboard`、`/api/stats?type=review-words`、`/api/words` 的 `exam/ids`、`/api/records` 的 `scope`。
3. 首页：设置持久化、学习路线、考试词表、今日面板、继续上次、文案清理。
4. 复习本：双 Tab、单词卡片、范围清空、批量重练。
5. 单词练习：两阶段反馈、真实用时、再来一组、移动端快捷键隐藏。
6. 句子练习：移除调试按钮、再练一轮重新抽题、移动端优化、开关文案。
7. 全局：减少动效、字体可读性、构建与手工验收。

## 10. 风险与后续

- **共享 SQLite**：当前仍是单机/单用户定位；公开部署前需要匿名用户 ID 或迁移到托管数据库。
- **考试词表覆盖**：`word_cefr` 只有 8460 词，部分考试词可能不在其中；后续可让考试模式直接查 `word_dict`。
- **复习规则简化**：当前以“正确次数 < 3”作为毕业条件，后续可升级为真正的 SRS。
- **数据统计口径**：单词按“作答次数”计，句子按“题次”计；首页统一叫“题数”，避免用户误解。
- **动效降级**：`prefers-reduced-motion` 只关闭装饰性动画，保留判分反馈。

## 11. 成功指标（后续埋点）

- 首页 → 开始练习的转化率。
- 次日回访率 / 7 日留存。
- 每日完成题数中位数。
- 复习本打开率与复习完成率。
- 单词第一次答错后的重试率。
- 考试词表选择占比。
